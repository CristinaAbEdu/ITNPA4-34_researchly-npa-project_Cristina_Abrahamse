# ITNPA4-34 Assignment 1
### From research text to meaningful insights

**Cristina Abrahamse | ITNPA4-34: Natural Language Processing**

Researchly brings together research abstract classification, article
summarisation and topic modelling in one NLP project. This repository
contains the documented analytical workflows for Questions 1–4, supporting
datasets and an interactive research abstract classification dashboard.

## Let's explore my project

### Questions 1 & 2 | Research Abstract Classification
`Notebooks` → `Q1& Q2_Research_Papers`

Follow the notebook through data preparation, text processing,
classification, model evaluation and model improvement.

Written explanations, code and saved outputs are organised by question
and subquestion. Question 2.3 introduces the Researchly web interface.

### Questions 3 & 4 | Research Corpus Analysis
`Notebooks` → `Q3 + Q4 Research Corpus`

Explore the research corpus through text preparation, article
summarisation and LDA topic modelling.

The folder includes the documented notebook, supporting corpus files
and an exported HTML topic visualisation. Download the HTML file and
open it in a browser to explore the interactive results.

## Researchly Dashboard | Question 2.3

The dashboard allows users to paste a research abstract and receive
a prediction of artificial intelligence research or classical research.

 `deployment/README.md`
Access the live dashboard link and instructions for running it locally.

 Top-level `Q1& Q2_Research_Papers`
Contains the dashboard application script and saved classification model.
Keep these files together, as the application loads the model from its
own folder.

 `requirements.txt`
Lists the Python dependencies for the dashboard application.

## Running the Analytical Workflows

1. Download and extract the complete repository.
2. Open the relevant notebook inside `Notebooks`.
3. Preserve the existing dataset and folder locations.
4. Set the working directory to the folder containing that notebook.
5. Use a Python environment with the packages imported by the notebook.
6. Run the cells in order, from top to bottom.

Saved outputs are included for reviewing the completed analyses.

**Dependency note:** The root `requirements.txt` supports the dashboard.
It is not a complete environment specification for all notebook analyses.
